---
description: 새 기능의 기획서(스펙)를 작성하고 구현 계획을 세운다
argument-hint: [기능 설명]
---

다음 기능에 대한 기획과 구현 계획을 작성해줘: $ARGUMENTS

절차:

1. 코드베이스를 탐색해서 관련된 기존 코드와 컨벤션을 파악한다
2. 아래 형식으로 스펙을 정리한다:
   - **목표**: 이 기능이 해결하는 문제 한 문단
   - **사용자 시나리오**: 누가, 언제, 어떻게 쓰는지
   - **범위**: 이번에 포함하는 것 / 포함하지 않는 것
   - **구현 계획**: 파일 단위의 단계별 작업 목록
   - **테스트 계획**: 어떤 케이스를 검증할지
   - **리스크**: 예상되는 문제와 대응
3. 스펙을 나에게 보여주고 확인을 받은 뒤에만 구현을 시작한다

구현 전에 반드시 계획에 대한 내 승인을 받아라.
