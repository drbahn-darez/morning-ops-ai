## 2. 확률 모델 — 왜 볼륨과 테스트가 핵심인가

편당 10만 달성 확률을 p, 월 시도 횟수를 N이라 하면 월 1편 이상 달성 확률 = 1 − (1 − p)^N.

| p (편당) | N = 8 | N = 12 | N = 20 | N = 30 |
|---|---|---|---|---|
| 1% | 8% | 11% | 18% | 26% |
| 3% | 22% | 31% | 46% | 60% |
| 5% | 34% | 46% | 64% | 79% |
| 10% | 57% | 72% | 88% | 96% |

- p는 **계정마다 다르고 아직 모른다**. 첫 4주간 자체 데이터로 기준선(중앙 조회, 상위 10% 조회)을 잡은 뒤 목표를 확정한다.
- [벤더] Socialinsider 2026 H1 브랜드 릴스 평균 조회: 1~5K 팔로워 580 / 5~10K 1,000 / 10~50K 2,460 / 50~100K 6,095 / 100K~1M 16,035. 즉 10만은 10~50K 계정 평균의 약 40배다.
- **p를 올리는 방법**: Trial Reels로 훅 2개씩 테스트(나쁜 훅을 정식 노출에서 제거), 상위 20% 패턴 재활용, 추천 적격성 유지.
- **N을 올리는 방법**: 제작 자동화(캐러셀 렌더러, ega-shorts 파이프라인), 배치 촬영, 콘셉트 하나를 릴스·캐러셀·Trial 변형으로 재사용.

## 3. 주간 운영 리듬 (브랜드당)

| 요일 | 작업 | 담당 |
|---|---|---|
| 월 | 지난주 분석 → 이번 주 플랜 (브리프 5~7개) | analyst → strategist |
| 월~화 | 배치 제작: 릴스 3 + 캐러셀 2 (+ Trial 변형 훅 2~3개) | producer, 촬영팀 |
| 화 | 검수 → 사람 승인 | reviewer → 대표/담당자 |
| 수~일 | 게시 (Trial 먼저, 24h 지표 보고 정식/중단) | publish 절차 |
| 매일 | 24h 진단 1줄 (조회·스킵률·공유/도달) | analyst |

**기본 포맷 믹스 (주당 최소, 브랜드 팩에 지정이 있으면 브랜드 팩 우선)**: 릴스 3 (그중 1개는 "10만 도전작": 가장 강한 훅 + 공유 동기) · 캐러셀 2 (음악 포함, 2번 장 단독 훅) · Trial 변형 2~3.
→ 월 릴스 12 + Trial 8~12 = 월 시도 N ≈ 20~24.

## 4. Kill / Scale 규칙 (자체 기준선 대비 — 벤더 절대값 사용 금지)

기준선 = 해당 브랜드 최근 30일 릴스 **중앙값**. 기준선이 4주 미만이면 판단 보류하고 "데이터 축적 중"으로 표기.

| 신호 (게시 24h) | 판정 | 액션 |
|---|---|---|
| 조회 ≥ 기준선 3배, 또는 공유/도달 상위 10% | **SCALE** | 7일 안에 같은 주제·새 훅으로 remix 2개, 캐러셀 버전 1개, 콜랩 후보 탐색. 광고 부스트는 사람 결정 |
| 조회 ≥ 기준선 1.5배 | KEEP | 같은 포맷 유지, 훅만 변주 |
| 스킵률이 기준선 대비 +10%p 이상 | HOOK FAIL | 첫 프레임·첫 문장 교체 후 Trial 재시도 |
| 시청 시간 양호 + 공유/저장 낮음 | PAYOFF FAIL | 엔딩·쓸모 강화 (체크리스트, 반전) |
| 3편 연속 기준선 미만인 필러/포맷 | KILL | 2주간 중단, 다른 필러로 교체 |
| Trial 72h 기준선 미만 | DROP | 정식 공유하지 않음 (그리드 노출 없음) |
