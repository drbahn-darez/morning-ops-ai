## 1. EGA — 식품·NMN
- **NMN의 국내 지위 미확정** [low]: 고시형·개별인정 기능성 원료로 확인되지 않음. 식품 원료 사용 가능 여부(식품의 기준 및 규격 별표1 / 한시적 기준·규격)도 미확인 → **NMN 리추얼 음료의 판매·제공 적법성부터 법무 확인 필요** (광고 문구보다 큰 문제).
- 확정 전까지 **NMN에는 어떤 기능 주장도 하지 않는다**: NAD+ 증가, 세포 회복, 항노화, 피로·에너지, "NMN = RECOVERY" 모두 금지.
- 자율심의 필수 대상: 건강기능식품, 기능성표시 일반식품, 특수영양식품, 특수의료용도식품 (시행규칙 제10조). 해당 SKU면 모든 게시물에 **심의 번호 + 승인 문구 그대로**.
- 일반식품 기능성 표시(고시 2024-62)는 좁다: 인정 기능성 원료만, 정제·캡슐·스틱 분말 제외, 필수 문구("본 제품은 건강기능식품이 아닙니다" 등). NMN은 해당 경로 사용 불가로 본다.
- **AI 가짜 전문가 추천 금지** — 식품 2026-11-27, 화장품 2026-11-27, 의료기기 약 2026-12-10 시행. 공정위 심사지침 Ⅴ.5(가상인물)는 이미 시행(2026-06-01).
- 안전한 음료 표현: 리추얼, 맛, 온도, 즐기는 방법, 사실로서의 성분('NMN ○mg 함유' — 라벨과 일치할 때만). 효과 동사 금지.

## 2. EGA — 사우나·콘트라스트 테라피
- **REJECT**: 치료·진료·재활·의학적 효과·통증 완화·염증·면역력 강화·디톡스(디지털 디톡스 제외)·독소 배출·혈압·혈당·우울증·불면증 개선·치매 예방·뇌 기능 개선·지방 연소·칼로리 소모·피부 재생·수명 연장·질병 예방·"의사 추천"
- **FLAG**(SCI/NRF 출처 + 일반 생리 정보로 프레이밍 + 질병 단어 없이): 혈액순환, 혈류, 심박, 자율신경, 스트레스 완화, 수면의 질, 근육 회복, 코르티솔, 도파민, 면역, 신체 효과 수치
- **안전 문구 필수**: 열·냉 노출 장면에는 "임산부·심혈관 질환자·음주 후 이용 자제, 어지러우면 바로 휴식" 류
- **안전한 어휘**: 휴식, 리추얼, 루틴, 개운함, 몰입, 리셋, 디지털 디톡스, 온·냉의 감각, 따뜻함과 차가움을 오가는 경험
- 방문자 후기 인용은 **느낌·분위기만**. "두통이 사라졌어요", "불면증이 나았어요" → REJECT

## 3. EGA — 화장품 (NMN 핸드크림 등)
- **REJECT**: 아토피·습진·피부염·여드름 치료, 상처 치유, 흉터 제거, 세포 재생, 줄기세포, 인체 유래 엑소좀, 보톡스·필러 효과, 의사 처방·병원 전용·피부과 전용, 피부나이 -N세, N년 어려짐, 어려진다, 리버스 에이징

- **FLAG**(인체적용시험 실증 필요, 소비자 설문은 불인정): 인체적용시험, 임상 완료, N% 개선, 저자극, 피부과 테스트, 무첨가, 리프팅, 탄력 N%

## 5. adro — 성능 수치·비교
- **수치 = 실증 자료 + 같은 장의 조건 표기** (표시광고법 제5조, 실증 고시 2026-15, 제한사항 가이드라인 예규 314). 조건: 차종·연식, 속도(km/h), 방법(CFD/풍동/트랙), 기준(순정 대비), 시험 주체, 날짜. 조건 글씨는 본문 대비 충분히 크게, 대비 4.5:1 이상, 릴스는 2초 이상 노출 [해석 임계값].
- **연비·전비·효율 주장은 실증 고시의 명시적 주요 대상**: 독립·인정 시험기관(KOLAS 등)의 실차 시험이 원칙, **계열사·자사 시험은 원칙적으로 불인정**(예외: 독립 기관 부재, 영업비밀, 과도한 비용). → **Tesla Model Y "전비 4.58%"는 자사 시험만으로는 광고 사용 보류.** 드래그 수치를 효율로 환산 금지.
- CFD로 얻은 드래그 % → FLAG + "CFD 시뮬레이션 결과, 실제 주행 결과와 다를 수 있음" 병기. "공기저항 15%"도 시험 방법·주체를 확인하고 법무 판단 전까지 FLAG.
- 최상급·순위(세계 최초, 유일, 1위, 업계 최고) → 근거 없으면 REJECT
- 경쟁사 언급(Ansys, Altair, Star-CCM+, 타 바디킷 브랜드) → 동일 조건·조건 공개·일반화 금지. 기본은 언급하지 않는다.
- **셀 수 비교(일반 CFD 10억 vs AOX 500만)도 비교 표시·광고** — 비교표시·광고 심사지침 Ⅲ.3상 객관적 근거 필요. 법무 확인 전 대외 게시 보류.
- "AI로 더 정확/안전" → 실증 대상 (FLAG)

## 6. adro — 튜닝·주행
- **REJECT**: 튜닝 승인 불필요 / 구조변경 안 해도 됨 / 검사 없이 / 단속 걱정 없음 / 100% 합법 / 불법 튜닝 아님 / 합법 장착 보장 / 번호판 가림 / 머플러 직관 / 배기음 증폭 (튜닝부품 인증번호 `meta.tuning_cert_id`가 있으면 FLAG + 본문에 인증번호 표기)
- **REJECT (증빙으로도 완화 불가)**: 칼치기, 폭주 운전, 공도 레이스·드래그
- 승인 대상(시행규칙 제55조): 길이·너비·높이, 총중량, 차체·차대, 등화, 소음·배출가스 등. 범퍼 외관 변경·튜닝인증부품·튜닝안전확인부품·경미 항목은 면제. **어떤 에어로 파츠가 '경미'인지(고시 별표1)는 미확인.**
- **장착점·파트너 정비업체 리스크**: 승인 없이 승인 대상 튜닝을 시공한 자동차관리사업자(정비업자)·제작자는 제57조②·제80조로 2년 / 2천만 (콘텐츠에서 '저희 매장에서 바로 장착' 류 문구는 승인 대상 여부 확인 후)
- 국내 대상 게시물에서 와이드 펜더·윙·전장 변경 파츠 → "국내 장착 시 튜닝 승인·검사 대상" 문구 또는 인증번호 (FLAG)
- 공도 주행 영상은 합법 속도·차분한 주행만, 트랙이면 '트랙 촬영 / closed course' 표기

## 7. 음원·영상·상표 (모든 브랜드)
- 저작권법 2026-08-11 시행 개정: **7년 / 1억 + 고의 침해 징벌적 5배**.
- 음원: 오리지널 / Meta Sound Collection / 라이선스 ID가 있는 곡만. 앱 인기 음원은 비즈니스 계정 라이브러리 노출·상업 사용 가능 여부 확인(FLAG).
- **Top Gear/BBC 영상, 타 크리에이터 클립, 방송·영화 클립은 라이선스 없이 사용 금지**. 워터마크 있는 크로스포스트 금지.
- Top Gear, BBC, UC Irvine, OEM 로고 등 타사 상표를 보증처럼 사용 → 서면 허가 범위 안에서만 (FLAG)

## 8. AI 콘텐츠
- **REJECT**: AI 생성 인물을 실제 고객·방문자·후기 작성자로, AI 의사·약사·교수·흰 가운 전문가를 식품·화장품·기기 콘텐츠에
- **FLAG**: AI 에셋 사용 시 `is_ai_generated=true` + 보이는 표기("AI 생성 이미지/음성 포함"). AI 기본법 제31조(2026-01-22)의 광고주 적용 여부는 불명확하지만 표기 비용이 낮다.

## 9. 미해결 — 법무 확인 목록
1. NMN의 식품 원료 사용 가능 여부와 기능성 원료 지위 → 리추얼 음료 판매·제공 적법성
