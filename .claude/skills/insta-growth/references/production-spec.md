# 제작 규격 (Production Spec)

> 기준일 2026-10-04. API 업로드 규격은 Meta 공식 SDK v26.0·문서 사본 기준(connectors/instagram-graph/README.md). 화면 세이프존은 업계 가이드 기준 [벤더/2차] — 앱 UI 변경 시 갱신.

## 릴스

| 항목 | 규격 | 근거 |
|---|---|---|
| 해상도 | **1080×1920 (9:16)** | API 권장 |
| 길이 | **20~60초 기본**, 10만 도전작도 **최대 90초**, 180초 초과 금지 (3분 초과 비팔로워 추천 제외 — [미검증]). API 허용 3초~15분 | [벤더] Socialinsider 2026 H1 도달률 30~60초 최고 |
| 코덱 | H.264 High, yuv420p, progressive, 30fps CFR, closed GOP, VBR ≤ 25Mbps / AAC-LC 48kHz 스테레오 128k | API 스펙 |
| 파일 | MP4, moov atom 선두(+faststart), **edit list 없음**, 300MB 이하 | API 스펙 ("no edit lists") |
| 정규화 | `tools/reels/prepare.sh in.mp4 [out.mp4] [crop\|pad]` — 기본 crop(검은 여백보다 크롭) | |
| 커버 | **별도 1080×1920 JPEG** (`cover_url`, sRGB, 8MB 이하; cover_url이 thumb_offset보다 우선). 렌더러 `size: "9:16"`, `layout: "cover"` → 텍스트가 y 300~1240에 배치되어 릴스 UI와 3:4 그리드 크롭(y 240~1680) 모두 통과 | API 스펙, [공식] 2025-01 그리드 3:4 |
| 워터마크 | 타 앱(CapCut·TikTok·YouTube) 워터마크 금지, 자사 로고 OK | [공식] Mosseri |

**첫 3초 설계 (스킵률 = 첫 3초 이탈 비율)**
1. 0.0~0.5초: 움직임 또는 대비가 있는 첫 프레임 (정지 타이틀 카드로 시작하지 않는다)
2. 0.5~1.5초: 화면 텍스트로 질문/약속 제시
3. 1.5~3초: 페이오프가 온다는 신호 (숫자, "3가지", 반전 예고)
- **소리 켜고 보는 전제로 설계**(목소리·음악이 이야기를 끌고 감) — "85% 무음 시청"은 2016년 페이스북 피드 수치로 릴스에 맞지 않음. Meta는 2024년 릴스 조회 75%+가 소리 켬이라고 밝힌 것으로 보도 [미검증].
- 그래도 자막은 항상 번인 (무음 시청자·접근성·화면 키워드). 국문 화면 텍스트 + (외국인 타깃이면) 영문 캡션.

**세이프존 (1080×1920 기준)** [Meta 릴스 광고 가이드 기준 — 오가닉 UI는 이보다 여유 있음. 광고 부스트까지 재편집 없이 쓰려면 이 기준]
- 상단 14% (269px), 하단 35% (672px), 좌우 6% (65px) 비우기
- → 핵심 텍스트·로고는 **x 65~1015, y 269~1248** 안에. 우측 하단 버튼 열 근처 금지
- 번인 자막: 흰색 + 4~6px 어두운 외곽선 또는 60% 박스, 최대 2줄, 자막 블록 하단 ≤ y 1240, 줄 폭 ≤ 950px
  - EGA(국문): Pretendard/Noto Sans KR Bold 60~68px, 한 줄 약 14~16자
  - adro(영문 우선): Inter Tight 800 64px 기준 **한 줄 27자 이하**(31자 = 975px로 세이프 폭 초과, 검수 실측), 국문 병기는 Noto Sans KR
  - 화면 훅 텍스트(Inter Tight 900 96px)가 950px를 넘으면 두 줄로 나누거나 88px 이하로
- 오가닉 UI 실측 픽셀은 Meta 미공개 → 각 브랜드 첫 게시 릴스 스크린샷으로 1회 보정

## 캐러셀

| 항목 | 규격 | 근거 |
|---|---|---|
| 비율 | **1080×1350 (4:5)** 기본 — API 경로. 모든 장 같은 비율(첫 장 비율로 크롭) | API 스펙 |
| 히어로 캐러셀 (앱 경로) | **1080×1440 (3:4), 사진만, 최대 20장, 앱에서 상업용 음악 추가** → 릴스 탭 노출 가능. API는 3:4·음악 미지원(v26 `audio_configuration` 파라미터 의미 미확인) → 승인 후 사람이 폰으로 게시. 렌더러 `size: "3:4"` | [공식] 2025-05-29 3:4 지원, 음악 캐러셀은 사진 전용 (help.instagram.com/1223433768344104) |
| 장수 | API **2~10장** (앱은 20장). 기본 7~10장 | API 스펙; [벤더] Socialinsider 2020 10장 최고 참여 |
| 포맷 | **JPEG, sRGB, 8MB 이하** — 렌더러 기본 출력 | API 스펙 |
| 그리드 크롭 | 4:5 이미지가 3:4 그리드에서 좌우 약 34px씩 잘림 → 좌우 여백 96px 유지(렌더러 기본) | 계산 |
| 음악 | 음악을 붙이면 릴스 탭 노출 가능 → 앱에서 게시할 때 음악 추가 (API는 미지원) | [공식] 2024-10 |
| 대체 텍스트 | 장마다 `alt_text` (1,000자) — 검색 색인에도 활용 | API 스펙 |

**구조 규칙**
- 1번 장: 영문 eyebrow + 국문 질문 헤드라인 (EGA 카드 문법) / 숫자·대비 (adro)
- **2번 장도 단독 훅** — 안 넘긴 사용자에게 2번 장부터 재노출됨 [공식·Mosseri]
- 본문 장: 제목 ≤ 2줄, 본문 ≤ 3줄, 3초 안에 읽힘. 한 장 한 메시지. 본문 최소 28px(렌더러 40~44px), 출처·면책 최소 24px
- 마지막 장: CTA 1개 (저장 / 보내기 / 프로필 링크). "댓글에 X 남기면" 류 금지
- 수치가 있는 장에는 `source` 필드로 출처 표기

**렌더러**: `node tools/carousel/render.mjs <spec.json> <outDir>` → `<id>_01.jpg …` + `<id>_sheet.png`
- 레이아웃: cover / text / list / stat / compare / quote / cta (스펙은 render.mjs 상단 주석)
- 강조: `**텍스트**` → 브랜드 액센트 컬러
- 긴 제목은 자동 축소(최소 40px). 축소가 일어났다면 문장을 줄이는 게 맞다.

## 캡션
- 첫 줄 = 훅 재진술 (피드에서 약 125자 이후 '더 보기'로 접힘 [업계 통설])
- 2,200자 이하, **해시태그 5개 이하** (2025-12 정책; 커넥터가 강제)
- 검색 키워드(국/영)를 자연스럽게 포함 — 2025-12 이후 프로페셔널 계정 게시물 Google 색인 [2차]
- 유료/협찬: 첫머리 `[광고]` 또는 `#광고` + 유료 파트너십 라벨 (compliance.md)
- AI 이미지 사용: `is_ai_generated=true` + 캡션 말미 "AI 생성 이미지 포함"

## 오디오 · 나레이션
- 비즈니스 계정은 상업용 라이선스 음원만. 인기 음원 사용 가능 여부는 앱에서 확인. [compliance.md]
- API로는 원본 오디오 이름(`audio_name`)만 지정 가능 — 라이선스 음원은 앱에서.
- 마스터 영상에 라이선스 음원을 굽지 않는다 (릴스·쇼츠 재활용 시 저작권 클레임, 쇼츠 60초 초과 + Content ID 클레임은 전 세계 차단 가능).
- **TTS**: edge-tts(ko-KR-SunHiNeural 등)는 비공식 클라이언트·24kHz 48kbps 모노 → **초안·내부 미리보기 전용**. 게시용 음성은 ElevenLabs(eleven_multilingual_v2 / v3, 한국어 지원, mp3_44100_192) 또는 Azure Speech(같은 ko-KR 뉴럴 보이스를 공식 라이선스로).
- 클라우드 세션에서는 edge-tts 엔드포인트(speech.platform.bing.com)가 프록시에 막혀 있음 → ega-shorts TTS는 맥에서 실행하거나 허용 도메인 추가.

## 재활용 (릴스 ↔ 쇼츠)
- 콘셉트당 **클린 9:16 마스터 1개** (플랫폼 UI·타사 로고·라이선스 음원 없음) → 플랫폼별 별도 export
- 플랫폼마다 첫 프레임 텍스트·캡션·제목을 새로 쓴다. 틱톡·유튜브에서 내려받아 재업로드 금지.

## 폰트
- EGA: Noto Serif KR (헤드라인), Noto Sans KR (본문), Cormorant Garamond Italic (영문 eyebrow)
- adro: Inter Tight (헤드라인·숫자), Noto Sans KR (국문), JetBrains Mono (라벨)
- 모두 Google Fonts(OFL). 렌더러가 첫 실행 시 `~/.cache/insta-carousel-fonts`에 캐시.
