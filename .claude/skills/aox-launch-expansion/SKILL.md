# AOX 런칭 & 확장 스킬

adro의 AOX CFD 소프트웨어가 오픈베타 → 11월 정식 출시(유료) → IPO 트랙션 페이지에 들어가기까지, **모든 산출물이 같은 사실·같은 톤·같은 내러티브**를 유지하도록 돕는 스킬입니다.

이 스킬의 목표는 단순한 문서 작성이 아니라, **베타 사용자 확보 → 유료 전환 → IPO 밸류에이션 멀티플 확보**로 이어지는 일관된 스토리라인을 만드는 것입니다.

3. **Efficiency** — 초기 디자인 단계부터 공기저항 검토 가능, 디자인 프로세스 내재화

### 1.1 베타 사용자 온보딩 자료

**언제 사용**: "베타 가이드", "AOX 사용법", "튜토리얼", "온보딩 메일" 요청 시

**필수 포함 요소:**
- 첫 실행까지의 시간(Time to First Value) 목표: **30분 이내**
- 핵심 워크플로우 3단계: Area proposal → Guide proposal → Design proposal
- 사용자 막힐 때 연락처 (CS 채널)
- 베타 사용자에게 명시할 약속: 피드백 시 **유료 전환 시 X개월 무상 사용권** 같은 인센티브

**출력 톤:**
- 디자이너 대상 → 공학 용어 최소화, "공기저항 → 드래그" 같은 직관적 표현 우선
- 한국어 베타와 영어 베타가 모두 가능하면 양 버전 모두 제공

**산출물 구조:**
```
1. AOX 베타에 오신 것을 환영합니다 (1-2문장 환영문, 인센티브 명시)
2. 30분 안에 첫 결과 보기 (Quick Start, 스크린샷/이미지 자리 표시)
3. 3가지 핵심 워크플로우
   - Area proposal (비효율 영역 자동 검출)
   - Guide proposal (수정 가이드 제시)
   - Design proposal (최적화된 형태 제안)
4. 자주 묻는 질문 (Top 5)
5. 피드백 채널 + 베타 한정 혜택
```

**가격 시뮬레이션 산출 시 반드시 포함:**

- **권장**: 베타 사용자에게는 첫 6개월 50% 할인 + 연간 결제 락인
- 2026-09-23 "정식 출시 전 팀 대상 스페셜 오퍼" 메일이 이미 발송됨 → 신규 제안은 이 오퍼와 충돌하지 않게 설계

### 1.6 IR / 이사회용 AOX 트랙션 리포트

**언제 사용**: "IR 데크", "투자자 미팅 자료", "이사회 보고", "AOX KPI 리포트" 요청 시

**IR이 매번 묻는 5가지 질문에 답이 있어야 합니다:**

1. **베타 사용자 몇 명?** → 절대 숫자 + WoW 성장률
2. **유료 전환율?** → 베타 → Paid 전환 %, 코호트별
3. **ARPU?** → 시트당 ARR
4. **OEM 도입 진행 상황?** → 파일럿 LOI 수, 계약 단계
5. **Software Revenue 비율?** → 전체 매출 중 % 추이

**IR 한 페이지 표준 템플릿:**
```
[ AOX Traction — YYYY-MM ]

Beta Users:     XXX  (WoW +X%, MoM +X%)
Active 7-Day:   XX%
Paid Conversion: XX% (target: 25% by Dec)

Revenue:
  ARR (실현):    ₩X.X억
  ARR (Pipeline): ₩XX억

OEM Pipeline:
  Engaged:   X social (BMW, Toyota, Hyundai-Genesis)
  Pilot LOI: X social
  Contract:  X social

Key Win This Month: [한 줄]
Key Risk This Month: [한 줄]
```

**작성 원칙:**
- **숫자가 없는 페이지는 만들지 않습니다.** 미정이면 "N/A (Q3 가이던스)" 명시
- 부정적 지표도 숨기지 않고, **대응책과 함께** 제시
- IR에서는 "성장률이 둔화된 이유"보다 **"우리가 무엇을 알게 되었고, 무엇을 바꾸는가"**가 핵심

### 1.7 OEM/파트너 미팅 후속 자료

**OEM별 맞춤 포인트:**

- **Toyota**: GR 브랜드 (Supra, GR86) + Mobility 변화 — 이미 실적 있음

## 2. 산출물 공통 톤 가이드

### 톤 원칙
- **직설적이고 숫자 중심** — 추상 표현 금지 ("좋은 결과" → "공기저항 15% 개선")
- **경영자/투자자 관점** — 모든 자료의 마지막 페이지는 "이게 왜 매출/밸류에이션에 영향을 주는가"
- **현실 우선** — 좋은 말보다 리스크와 대응책을 함께
- **실행 순서까지 명시** — "검토 필요"가 아니라 "다음 주까지 X를 결정"

### 한국어 vs 영어
- **내부 자료 (이사회/CEO 보고)**: 한국어 기본
- **OEM/투자자 미팅**: 영어 우선, 한국어 병기 옵션
- **베타 사용자 자료**: 사용자 언어 (한국 베타 → 한국어, 글로벌 베타 → 영어)
- 사용자가 별도 지시 없으면 **한국어로 작성**

### 시각 자료 가이드
- adro 브랜드 컬러: **블랙 / 화이트 / 레드 포인트** (전략 문서 기준)
- 차트는 단순하게 — 막대/원형 1-2개만, 라벨은 굵게
- "30%" 같은 핵심 숫자는 페이지에서 가장 큰 요소

## 3. 흔한 실수 방지

이 스킬을 사용할 때 자주 발생하는 실수입니다. 반드시 피하세요.

### ❌ 실증 없는 성능 수치를 대외 광고에 사용
- 공정위 「표시·광고 내용의 실증에 관한 운영고시」(2026-15, 2026-09-03 시행)는 **연비·효율 개선, % 효능, 순위, 'AI 기술로 더 정확/안전'** 을 주요 실증 대상으로 명시하고, 원칙적으로 **독립·인정 시험기관** 시험을 요구한다(자사·계열사 시험 불인정, 예외 있음).
- "Tesla Y 전비 4.58%"는 웹·SNS·광고성 자료에 쓰기 전 법무 확인. "공기저항 15%"는 시험 방법·주체·조건을 같은 페이지에 표기. IR·비공개 미팅 자료는 별개지만 출처와 조건은 항상 병기한다.

### ❌ 추상적 메시지
- "AOX는 혁신적인 솔루션입니다" → ❌
- "adro 자체 테스트에서 Tesla Model Y 공기저항 15% 감소 (조건: 차종·속도·측정 방법·순정 대비)" → ✅ (내부·비공개 자료. 대외 광고는 실증 후)

### ❌ Ansys를 직접 비방
- "Ansys는 비쌉니다" → ❌ (그쪽 영업이 더 잘함)
- "AOX는 디자인 단계에서 사용 가능한 새로운 카테고리입니다" → ✅

### ❌ 베타 = 끝이 아니다
- 베타 자료에서 "참여해 주셔서 감사합니다" 만 → ❌
- **유료 전환 인센티브를 베타 첫날부터 명시** → ✅

### ❌ 숫자 없는 IR 페이지
- "베타 사용자가 늘고 있습니다" → ❌
- "베타 사용자 N명, WoW +X%, 7일 리텐션 XX%" → ✅

### ❌ 카테고리 혼동
- AOX = 소프트웨어. 카본 파츠 / Bumper / Wing은 하드웨어.
- 자료에서 두 사업을 묶을 때는 명시적으로 "Hardware + Software 통합 솔루션"으로 표현

### ❌ IPO 내러티브 분리
- AOX 자료를 만들 때 매번 묻기: **"이게 2027년 9월 상장예비심사(전문평가 27.4~6월) 자료의 어느 페이지에 들어가는가?"**
- 답이 없으면 그 자료는 우선순위가 낮은 것입니다.
