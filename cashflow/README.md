# EGA 캐시플로우

bizindex 대시보드 옆에 두는 **현금 관점** 화면. 회계상 이익이 아니라 실제로 남는 현금을 계산한다.

## 계산 순서

1. **실매출** = 총매출(부가세 포함) ÷ (1 + 부가세율). 부가세는 예수금이므로 현금에서 분리.
2. **광고비 차감 후 현금** = 실매출 − 광고비. 광고비는 매일 실제로 나가는 돈이라 즉시 차감.
3. **순현금흐름** = 광고비 차감 후 현금 − 고정비(월 금액을 기간 일수로 안분) − 기타 지출.
4. **기말 예상 현금** = 기초 현금 + 순현금흐름.

매출원가는 이미 결제된 재고 비용이라 현금흐름에서 빼지 않는다. 원가율을 넣으면 회계상 매출이익을 참고용으로만 옆에 보여준다.

## 사용

- `cashflow/index.html` 하나로 동작. 서버 없이 브라우저에서 열면 된다.
- 기간: 이번 달 / 최근 7일 / 최근 30일 / 지난 달 / 전체.
- 일별 입력: 날짜, 총매출, 광고비, 기타 지출, 메모. bizindex나 엑셀에서 복사한 표를 “붙여넣기 (CSV)”로 한 번에 가져올 수 있다 (탭/쉼표 구분, 같은 날짜는 덮어씀).
- 데이터는 브라우저 localStorage에만 저장. 다른 기기로 옮길 때는 “JSON 복사”.
- 처음 열면 예시 데이터가 들어 있다. 값을 고치거나 “비우기”를 누르면 예시 표시가 사라진다.

## 배포

정적 파일이므로 bizindex와 같은 호스트의 하위 경로(예: `/ega-woong/bizindex/cashflow/`)에 그대로 올리면 된다.
